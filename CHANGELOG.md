# Changelog

All notable public-facing changes are recorded here. Dates and release links are
added only when a release is actually published.

## [Unreleased]

### Added

- Public-adoption metadata for the `v0.2.0a1` preparation.
- MIT licensing and canonical GitHub project metadata.
- Editable-install and `r3radar` console-script metadata.
- English landing README and retained Chinese operational documentation.
- Capability, architecture, evaluation, contribution, conduct, and citation
  documentation.
- Deterministic onboarding commands and module-form fallbacks in the documented
  alpha workflow.
- A zero-network, zero-model-call two-item demo with explicit synthetic labels.
- A redacted `doctor` report and non-overwriting profile generator.
- Deterministic public-source packaging with explicit allowlisting and
  fail-closed license gating.
- Privacy, security, single-tenant pilot, and third-party dependency boundaries.
- Offline repository-corpus reprojection with call planning, budget feasibility,
  immutable old analyses, and explicit apply semantics.

### Changed

- Public positioning now emphasizes decision-grade paper-and-code radar behavior
  instead of a single hard-coded research question.
- Report examples require an explicit `--run-id`.
- Evaluation claims distinguish engineering regression, deterministic demo,
  historical focus-run evidence, and the missing human relevance benchmark.
- The dashboard now derives its title and question from the active profile,
  defaults to a compact decision inbox, and keeps operational detail
  collapsible but visible when active.

### Known alpha boundaries

- The complete hardened path is Windows 10/11 with CPython 3.10.
- Linux, Docker, PyPI publication, multi-user hosting, and a managed service are
  not claimed.
- Historical deep reads do not establish current-policy model quality.
- No prospective human-labeled relevance benchmark has been completed.
